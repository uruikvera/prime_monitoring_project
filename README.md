## Что здесь

Проект посвящен автоматизированной системе мониторинга ключевых показателей продукта "ПРАЙМ".
На данный момент работа проводится с таблицей `transactions` по своему участку данных: канал `pos`, период
01.09.2025 — 30.09.2025, считаются метрики по этому срезу. Проект развивается и будет расти. 

Данные продукта "ПРАЙМ" - синтетические.
"ПРАЙМ" - платная подписка цифровой экосистемы, с доступом к партнерским сервисам и кешбеку.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:uruikvera/prime_monitoring_project.git
cd prime_monitoring_project
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```
